# 知潮 3.0.72 发布文案

> 状态：待正式 arm64 APK 核验后，由 `scripts/prepare-release-3.0.72.mjs --apply`
> 在同一受控操作中写入官网。APK 字节数、SHA-256 与发布时间不得预填或估算。

## 官网首屏

- 标题：英语学习、足迹与找功能，继续变得更顺手
- 摘要：复习和模考更完整，九图足迹可以点开看大图，自然语言找功能也会把入口说明白。

## 四项更新亮点

1. **复习**：遗忘曲线不只展示数据，也会把到期词卡排进今天的复习队列。
2. **模考**：新增 25 分钟英语模拟考试，覆盖单项选择、完形填空与阅读理解；提交后可查看逐题解析。
3. **足迹**：一次最多选择九张图片，按图片数量自动排版，支持点开看大图；此刻状态最多三项、标签最多五项。
4. **找功能与装扮**：“问朵朵·找功能”补充名称和说明并改进“病历”等自然语言命中；已穿戴装扮同步到足迹封面、悬浮朵朵和截图问朵朵的配色与边框。

## 更新日志

**知潮 3.0.72：英语复习、九图足迹与找功能体验升级**

英语刷卡学习补齐由服务端掌握度驱动的到期复习队列，并新增 25 分钟模拟考试，
覆盖单项选择、完形填空和阅读理解，提交后可查看逐题解析；每日本新词仍设上限，
四本词书当前先提供已校验的首组内容，后续内容会按校验结果扩充。
足迹一次最多选择九张图片，按数量自动排版并支持点开看大图，此刻状态与标签可多选；
已穿戴装扮会同步影响足迹封面、悬浮朵朵和截图问朵朵的配色与边框。
“问朵朵·找功能”补充入口名称、说明和命中理由，并改进“病历”等自然语言表达的匹配。
医疗内容改为分级提示，避免把普通学习与生活内容一概拦截；黄赌毒政、未成年人犯罪、
暴力以及提示词注入和越狱防护继续启用。AI 生成的学习内容可能有误，请结合教材、
考试大纲和可靠来源核对。

## 下载页四条

1. **复习与模考更完整**：到期词卡会进入今天的复习队列，也可开始覆盖三类题型的限时模拟考试。
2. **足迹支持九图与大图查看**：图片按数量自动排版，点开即可查看大图，状态与标签可多选。
3. **找功能会把入口说明白**：搜索结果补充名称、用途和命中理由，并改进“病历”等自然语言表达。
4. **装扮视觉联动更多入口**：足迹封面、悬浮朵朵与截图问朵朵会跟随当前装扮切换配色与边框。
