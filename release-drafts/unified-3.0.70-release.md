## App 新功能引导候选

1. `刷卡学习`：四本英语词书从首组开始，翻卡、补全、词测和到期复习走同一学习进度。
2. `朗读与听书`：单词、知识卡片和朵朵笔记共用一套口音、语速与播放控制；设备缺少可用语音包时会提示降级。
3. `问朵朵·找功能`：描述想做的事即可获得可点击入口；未开启 AI 数据授权时仍可使用本机匹配。
4. `提醒交给系统`：可选择系统闹钟、系统日历或知潮普通通知；打开系统页面后仍需由用户确认保存。
5. `足迹与分享`：足迹按日整理并修复图片显示；学习成就、图示和文档可使用统一分享落款。
6. `正版与内容保护`：官方安装包会核对签名；被修改或重新签名的安装包可能无法运行，请从 `huaix.cn` 获取正版。

## 正式发布材料生成门

1. 从最终集成提交构建唯一 APK；只接受 `3.0.70(107)`、`com.huaix.zhichao`、预期 ABI 与官方签名全部一致的成品。
2. 记录 APK 绝对路径、字节数和小写 64 位 SHA-256；官网部署后再次从公开 URL 下载并比对完整哈希。
3. 只读核对生产 server 提交、schema 71、迁移回执、健康状态、当前发布配置和上一条 `noticeId`；任何 pending migration 或身份漂移均停止发布。
4. 发布脚本默认只 preview。apply 必须同时要求：精确 APK SHA-256、精确预期用户数、精确用户集合 SHA-256、独立显式 approval，以及用户已经说“发”。
5. preview 输出目标用户数量与摘要、现有同文案行数、当前/候选发布配置和公开 APK 哈希；apply 后只读复核发布配置、目标覆盖、唯一时间戳与去重结果。响应不确定时先查库，禁止盲重试。
6. 官网 `APP_VERSION`、更新日志、下载文件与服务端发布配置必须属于同一候选；草稿、历史 3.0.68/3.0.69 APK 或旧哈希不得混入。
